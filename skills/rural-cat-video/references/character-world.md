# 角色与世界模板

新建角色、局部改色，或续作出现身份与场景漂移时使用。保留已经确认的内容，只填真正缺少的字段。

## 双猫关系卡

| 字段 | 角色 A | 角色 B |
|---|---|---|
| 外形与识别点 | 体型、毛色、眼睛、尾纹 | 体型、毛色、眼睛、尾纹 |
| 当集想做的事 | 一项具体目标 | 一项具体目标 |
| 真本事 | 能改善工序的猫动作 | 能改善工序的猫动作 |
| 本能与毛病 | 会被什么吸引 | 会被什么吸引 |
| 闯祸后的反应 | 可见动作 | 可见动作 |
| 关系变化 | 从开始到结束的变化 | 从开始到结束的变化 |

不要把一只猫固定为全能老师，另一只固定为只会闯祸。先通过动作让观众认识它们，再考虑饰物。

## 角色母图任务模板

```text
为[角色名]生成独立写实猫咪角色母图。
外形：[成年/幼猫、体型、毛长、毛色、眼睛、脸型、尾纹]。
识别点：[一个稳定花纹或少量饰物]。
正常猫科身体、四肢和猫掌；干净中性背景，柔和均匀光线，可见全身，不加文字。
姿态体现[好奇/沉稳等可由姿态表现的特质]。
复用已有参考时，保持同一只猫的脸型、体型和花纹。
```

角色不对称时，添加解剖方向，例如：

```text
猫自身右半头为黑毛，左半头为白毛。
正面观看时，黑色半头在观众画面左侧；转头后仍沿猫自身解剖方向保持。
```

局部修改写“改什么、保留什么”，不要重新随机生成整只猫。

相对尺寸比空泛的“大、小”有用，例如“篮口宽度刚够两只猫并坐”。关键道具可另做参考图，也可从已有视频选清晰帧；标明图的来源。

## 从本能接到工序

下面是策划组合，不是固定剧情，也不保证模型能一次完成：

- 圆物滚动 → 前爪拨弄 → 物件滚错位置 → 同伴阻拦。
- 绳头摇晃 → 转耳注视、伸爪 → 工作分心 → 自己也失手。
- 柔软团块 → 交替踩奶 → 压成较平整形状 → 同伴观察并模仿。
- 食物完成 → 嗅闻、舔鼻 → 姿态放松 → 贴靠休息。

给每个动作一个可见结果。把复杂的“翻飞接住”改成沿桌推、沿锅托等有稳定支撑面的动作。
